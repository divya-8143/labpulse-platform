# LabPulse Platform — User & Clinician Manual

## 1. Getting Started as a Patient
1. **Sign In**: Navigate to `/login` and select **1-Click Demo Patient (John Doe)**.
2. **Upload a Report**:
   - Go to the **Upload Report** tab.
   - Drag & drop a PDF or scanned lab report (or select one of the sample PDFs in `synthetic_data/samples/`).
   - Click **Digitize & Extract Biomarkers**.
3. **Review Results**:
   - View your extracted test values, reference intervals, and flagged anomalies.
   - Inspect non-diagnostic summary insights and download the official PDF summary.
4. **Track Longitudinal Trends**:
   - Go to **Biomarker Trends** to visualize parameter changes over time with shaded reference corridor bands.

## 2. Getting Started as a Doctor
1. **Sign In**: Navigate to `/login` and select **1-Click Demo Doctor (Dr. Evelyn Reed)**.
2. **Patient Roster**: Review assigned patients, total digitized reports, and flagged anomalies.
3. **Verify & Comment**:
   - Review extracted values alongside original records.
   - Attach physician clinical impression, dietary advice, and follow-up notes.
   - Apply the official verification stamp.
